# Ahmed Khaled - Portfolio (2024 version)

A static, single-page personal portfolio site from August 2024, written in plain HTML, CSS and a small JavaScript file. It is an early project and is no longer my main showcase. My current work is on my [GitHub profile](https://github.com/KEPV18).

## What is on the page

Sections in `index.html`: About Me, Services, Skills, Projects, Certificates, Blog and Contact Me. The page title is bilingual (English and Arabic).

## Built with

- HTML and CSS (`index.html`, `styles.min.css`, with a `styles.scss` source file that is empty in this repo)
- Bootstrap 5.3 (CDN), Font Awesome and Google Fonts (CDN)
- AOS (animate on scroll) for scroll animations
- A small minified script, `scripts.min.js`

## Run it

There is no build step. Open `index.html` in a browser, or serve the folder with any static file server.
